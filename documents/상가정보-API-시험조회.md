# 상가정보 API 시험 조회

## 목적

KAN-27 상권회복 신호의 가맹점 후보 원천인 D1을 실제로 조회한다. 시험 페이지는 조회 전용이며, 응답을 가맹점 시드·런타임 DB에 저장하거나 쿠폰 발급 후보에 연결하지 않는다.

## 환경 설정과 실행

- API 인증키는 `apps/api/.env`의 `DATA_GO_KR_SERVICE_KEY`에 설정한다. `.env.example`에는 변수 이름만 제공한다.
- 실제 `.env`는 기존 ignore 규칙으로 Git에서 제외하며 권한은 `600`으로 설정한다. 키를 브라우저용 `VITE_` 변수에 넣지 않는다.
- API 시작 시 `src/bootstrap/local-env.ts`가 `apps/api/.env`를 읽는다. 외부에서 주입한 같은 이름의 환경변수가 우선한다. 파일이 없어도 서버는 시작하며 해당 API 요청에 설정 오류를 반환한다.
- 루트의 기존 `pnpm dev` 실행 후 `/store-api`로 이동하거나 상단의 **상가정보 테스트** 메뉴를 누른다. 이미 서버가 실행 중이라면 환경변수 적용을 위해 재시작한다.
- Encoding 키와 Decoding 키 모두 지원한다. 저장된 키를 한 번 디코딩한 뒤 `URLSearchParams`로 요청을 생성하여 이중 인코딩을 막는다.

## 요청과 응답

- 브라우저 → `GET /api/store-api/stores` → 서버 → 공공데이터포털 `storeListInDong` 순서다.
- 공급자 주소는 `https://apis.data.go.kr/B553077/api/open/sdsc2/storeListInDong`으로 고정한다.
- `divId`: `ctprvnCd`(시도 2자리), `signguCd`(시군구 5자리), `adongCd`(행정동 8자리).
- `key`: 해당 행정구역 코드. 기본은 대전 전체 `30`, 시군구 전환 시 대전 중구 `30140`이다.
- 지역은 공식 전체 목록의 이름과 코드로 선택한다. 시군구·행정동은 상위 지역에 속한 항목만 제공한다. 전체 대응표는 [공공 코드 안내](공공데이터-코드/README.md)에 있다.
- 업종 선택 필드: `indsLclsCd`, `indsMclsCd`, `indsSclsCd`. 비워두면 전체 업종을 요청한다. 공모전 CSV의 업종 코드를 그대로 입력하는 필드가 아니다.
- 업종은 공식 전체 대·중·소분류를 사용한다. 하위 분류를 선택하면 부모 분류가 함께 선택되며, 부모를 바꾸면 자식 선택이 초기화된다. 서버도 코드 존재 여부와 부모 관계를 검증한다.
- `pageNo` 기본 1, `numOfRows` 기본 20. 시험 페이지는 요청당 최대 100건으로 제한한다. 공급자 가이드의 최대치는 1,000건이다.
- 응답은 기준월·총건수·페이지·요청 소요시간과 상가업소번호·상호·지점명·구군·행정동·업종·주소·좌표를 제공한다.
- 화면의 JSON은 필요한 필드만 추린 응답이다. 공급자 응답 원문이나 인증키가 들어간 요청 URL은 전달하지 않는다.
- 서버의 공급자 요청 제한시간은 15초다. HTTP 실패, JSON이 아닌 인증 오류, 공급자 결과코드 오류, 응답 구조 오류를 빈 조회 결과와 구분한다.

## 확인 기록

- 2026-09-15 — 사용자 제공 OpenAPI 활용가이드 2026-08-05판에서 지역별 상가조회 명세를 확인했다.
- 2026-09-15 — 설정한 환경변수와 구현한 서비스로 대구 전체 1페이지 2건을 실제 읽기 전용 조회했다. 정상 응답, 기준월 `202606`, 전체 `118357`건, 반환 2건이며 상호·업종·주소·좌표를 확인했다. 이 수치는 조회 시점의 응답이며 최신 시점의 개별 가게 영업 상태를 보증하지 않는다.
- 인증키 인코딩·응답 비노출·잘못된 입력·XML 오류·키 누락의 서버 테스트와 페이지 조회·오류 표시 테스트를 작성했다. 사용자 지침에 따라 자동 테스트·빌드·타입 검사·브라우저 E2E는 실행하지 않았다. 실제 조회는 서비스와 공급자 API 사이의 연결 확인이며 화면 전체 검증을 뜻하지 않는다.

## 결정

- 2026-09-15 — 코드 입력란을 공식 지역·업종 목록의 연동 선택으로 바꾸고, 전체 대응표와 재수집 스크립트를 추가했다. 상가 12곳의 표본 업종만으로 선택 목록을 제한하지 않는다.

- 2026-09-15 — 후속 사용자 요청으로 기존 시연 가게 12곳을 대전 공공 상가 12곳으로 교체했다. `PublicStoreSnapshot`, `PublicDataMerchant`, `MerchantContent` 타입과 출처 정보를 추가하고 시드·런타임·벡터·시연 소비 이력·기존 시연 쿠폰을 함께 맞췄다. API 시험 페이지 자체는 계속 조회 전용이다.

- 2026-09-15 — 사용자 요청에 따라 시험 페이지와 서버의 기본 조회 지역을 대전으로 변경한다. 기존 대구 실제 조회 기록은 당시 확인 결과로 유지한다.

- 2026-09-15 — 사용자 요청에 따라 서버 환경변수에 인증키를 설정하고 독립된 시험 조회 페이지를 추가한다.
- 2026-09-15 — 인증키는 서버에서만 사용하고 조회에는 HTTPS를 사용한다. 이번 기능은 지역별 상가조회 하나로 제한한다.
