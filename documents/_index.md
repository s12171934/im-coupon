- [ ] **저장소 구조와 기술 스택** — React+Vite / NestJS / JSON 파일 DB / pnpm·Turborepo 모노레포, `apps/`·`packages/` 분리

- [ ] **프로토타입 범위** — 목 데이터 추상화 방침, 파라미터로 빼 둘 값(분배 비율·기한·금액)

## 이 파일을 갱신하는 규칙

- 문서를 만들거나 지웠으면 "문서 목록"을 같은 커밋에서 갱신한다. 목록에 없는 문서는 없는 문서다.
- 결정은 각 주제 문서에 `- YYYY-MM-DD — <결정 한 줄>` 로 쌓는다. 뒤집힌 결정도 지우지 않고 뒤집은 사실을 새 날짜로 적는다.
- 날짜는 절대 날짜로 적는다. "어제", "지난주"는 쓰지 않는다.
- 맨 위 "갱신" 날짜를 함께 고친다.
- 저장소 밖 원본을 가리키지 않는다. 근거는 여기에 직접 옮겨 적는다 (`documents-first` §6).
